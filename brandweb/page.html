接入文档

接口与 OpenAI 协议兼容，已有的 SDK 和工具只需替换接口地址与密钥。

1. 准备

向 {{.Name}} 客服获取接口地址（Base URL）与 API 密钥。密钥等同于账号凭证，请勿写入前端代码或公开仓库。

2. 发起对话请求

curl https://<接口地址>/v1/chat/completions \
  -H "Authorization: Bearer <API 密钥>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "<模型名称>",
    "messages": [{"role": "user", "content": "你好"}]
  }'

模型名称见模型价格页。需要流式输出时在请求体中加入 "stream": true。

3. 使用 SDK

from openai import OpenAI

client = OpenAI(base_url="https://<接口地址>/v1", api_key="<API 密钥>")
reply = client.chat.completions.create(
    model="<模型名称>",
    messages=[{"role": "user", "content": "你好"}],
)
print(reply.choices[0].message.content)

4. 常见错误

401
密钥无效或已停用，请检查 Authorization 请求头。
403
当前密钥无权使用该模型或线路。
429
请求过于频繁，请降低并发后重试。
5xx
服务暂时不可用，建议使用指数退避重试。
