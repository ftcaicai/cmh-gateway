**HTTP 契约与静态/Host 隔离通过；完整浏览器登录→自动回跳未验，P0 暂不标记完成。**

本记录修正前一轮误判：当前官方不是“Cookie 直接鉴权 self”。实际流程为 `new_api_refresh` HttpOnly Cookie → `POST /api/user/auth/refresh` → 短期 Bearer → `GET /api/user/self`。Cookie-only self 实测为 401。官方页面路由为 `/sign-in`，不是 `/login`。
