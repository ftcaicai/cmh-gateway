- 后端业务留在 `ext/brand/`，独立表以 `cmh_` 开头，由 `ext/migrations/` 管理；不加官方表列。

- 扩展迁移采用显式本地/运维命令，和请求服务分开；服务遇缺失表应给清晰不可用状态，不忽略错误后宣称可用。具体命令与失败传播仍需实现和验收。
- 前端位于 `web-cmh/`，复用官方导出组件；官方 `web/` 不新增菜单。工作台内部完整导航与明显入口先在扩展自身完成。
